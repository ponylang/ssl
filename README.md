# ssl

The ssl package is now part of ponyc's standard library.

The SSL/TLS networking support from ssl/net was incorporated into the standard library's [`net` package](https://github.com/ponylang/ponyc/tree/main/packages/net). The cryptographic primitives from ssl/crypto are in the standard library's [`crypto` package](https://github.com/ponylang/ponyc/tree/main/packages/crypto).

This repository is archived.
